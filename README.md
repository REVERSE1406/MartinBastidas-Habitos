# Tablero de Hábitos 

Una aplicación web sencilla para gestionar metas diarias. Mi app permite agregar, tachar y eliminar hábitos de una lista, guardando el progreso automáticamente en el navegador.

## Características
* **Gestión básica:** Agrega nuevos hábitos, márcalos como completados o elimínalos.
* **No pierdas tus datos:** Uso de `localStorage` para que la lista sobreviva al recargar la página.
* **Manipulación del DOM:** Todo funciona en una sola página sin recargas, usando JavaScript.

## Tecnologías
* HTML & CSS (Bootstrap 5)
* JavaScript (ES6, manipulación del DOM, delegación de eventos)
* Control de versiones con Git (Ramas y Merges)
